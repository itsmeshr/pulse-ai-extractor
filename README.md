# 🧠 Pulse: AI-Powered Documentation Mapper

**Pulse** is a robust Full-Stack AI tool designed to convert complex B2B technical documentation into interactive, hierarchical knowledge graphs. It utilizes **Google Gemini 2.0 Flash** to parse unstructured web content and **Graphviz** to render the results as a Directed Acyclic Graph (DAG).

---

## Features
- **AI Extraction:** Uses Gemini to identify modules and submodules.
- **Interactive Visualization:** Generates real-time DAGs.
- **Resilient Architecture:** Includes fallback modes and rate-limit handling.

## Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **AI:** Google Gemini API
- **Visualization:** Graphviz

## 🚀 Setup & Usage

### 1. Installation
Clone the repository and install the required dependencies:
```bash
git clone [https://github.com/YOUR_USERNAME/pulse-ai-extractor.git](https://github.com/YOUR_USERNAME/pulse-ai-extractor.git)
cd pulse-ai-extractor
pip install -r requirements.txt
```
###2. Environment Configuration
Create a .env file in the root directory and add your Google Gemini API key:
**Code snippet**
```GEMINI_API_KEY=your_api_key_here```

###3. Running the Application
Launch the Streamlit dashboard:
```bash
streamlit run app.py
```
**How to use:**
Paste a documentation URL (e.g., https://www.chargebee.com/docs/2.0/).
Set the "Depth" slider (1 is recommended for speed and API safety).
Click "Run Analysis" to generate the visual hierarchy and JSON output.

##🏗️ Technical Architecture
The application follows a modular 3-tier structure to ensure scalability and separation of concerns:
**Frontend (Streamlit)**: Manages the user interface, input validation, and real-time rendering of the DOT source code generated by the AI. It provides an interactive slider for crawl depth and a clear visualization panel.
**Orchestration Layer (app.py)**: Coordinates data flow, manages session states, and handles the extraction of text from source URLs using the requests and BeautifulSoup libraries.
**AI Engine (core/agent.py):**
LLM Integration: Connects to the Gemini 2.0 Flash model via the Google Generative AI SDK.
Data Modeling: Uses Pydantic to enforce a strict JSON schema. This ensures the AI output is reliable, contains confidence scores, and matches the format required for Graphviz rendering.

##🧠 Approach & Design Rationale
**Model Selection**: Gemini 2.0 Flash was selected for its high token-per-second speed and large context window, allowing it to "read" long documentation pages effectively without losing context.
**Visualization Engine**: Graphviz was chosen over other libraries because its hierarchical layout algorithms (DOT) are specifically optimized for representing tree-like structures found in software modules, providing a much clearer "Mental Map" than standard force-directed graphs.
**Structured Output**: By using Pydantic classes, the system guarantees that every AI response contains the necessary fields (module_name, description, submodules) required for the UI to function without crashing, effectively solving the "unstructured output" problem of LLMs.

##⚠️ Assumptions & Edge Case Handling
**Rate Limiting**: To handle the Gemini Free Tier limits (15 RPM), the system includes a "Smart Wait" mechanism and retry logic for 429 Resource Exhausted errors.
**Deep Nesting**: For deeply nested sites like Chargebee, the system utilizes a breadth-first approach, focusing on extracting the most relevant structural headers first to stay within token and rate limits.
**Sparse Content**: If a page has minimal text, the AI is prompted to focus on the URL path and navigation metadata to infer the module's purpose and relationship to the parent node.
**Privacy**: Sensitive API keys are managed via environment variables and excluded from version control using a .gitignore file.
