# Pulse: AI-Powered Documentation Mapper

**Pulse** is a Full-Stack AI tool that converts complex technical documentation into interactive visual knowledge graphs. It uses **Google Gemini 2.0 Flash** to analyze text and **Graphviz** to render hierarchical structures.

## Features
- **AI Extraction:** Uses Gemini to identify modules and submodules.
- **Interactive Visualization:** Generates real-time DAGs.
- **Resilient Architecture:** Includes fallback modes and rate-limit handling.

## Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **AI:** Google Gemini API
- **Visualization:** Graphviz
